Publish the database rules

Firebase console: Realtime Database → Regole (Rules) / Rules → Pubblica (Publish).

1

Open the Rules page

2

3

  1. Tap in the editor and delete everything, until the editor is completely empty (check by scrolling down: no braces must be left).
  2. Paste. The rules are one single long line: the editor must show only line 1.
  3. Tap Pubblica (Publish).

Error "Mismatched '}'" on line 2 or later means old text was left over: delete everything and paste again.
